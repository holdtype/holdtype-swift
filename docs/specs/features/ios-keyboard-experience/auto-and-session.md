`Auto` replaces Translate/Improve icons. Compact popover has independent
`Translate Result`/`Correct Result`; closed neutral key has downward chevron and
selected count, intrinsic Dynamic Type-safe width, no clipping. No Clear/Append;
host text is preserved and result inserts once. Center microphone is sole Start.
Valid toggle keeps popover open; it closes on Auto/outside/Quick Insert, not state
change. Opening returns Voice and closes Quick Insert.

Incomplete Translation stays off and opens exact app field/guidance. Correction
forces saved model/prompt without preference change and safely falls back to
accepted transcript. Both combine correction then translation. Defaults off per
extension lifetime, persist only there, independent of app Voice/Settings. Auto
remains selectable in every phase/setup state. Freeze at Start; later changes next request.

Cold valid microphone creates fixed bounded app session and first capture; no
manual prep/configurable lifetime/permanent background/Live Activity. Ready uses
static full-color cyan app artwork with low-energy side waves, no mic/logo/Ready
label. Acknowledged real capture alone yields Listening; same centered cyan
orbits/pulse and deterministic decorative waves, never metering; tap Finish, no
adjacent Cancel. Opening/Starting use bounded slow opacity without height-meter
claim. After stop use centered unavailable purple recognition/slower waves.

Exact live owned host permits one insertion; dismissal/restart/host/request
uncertainty preserves Latest for explicit action. One Voice chain owns microphone.

Starting…, Listening…, Processing…, Dictation failed. No transcript/manual route;
