44-pt Fixes, trailing 44-pt History then Latest, all neutral keys matching editing
surface; workspace directly toggles Voice/Quick Insert/Fixes and close restores

control, never status; all state stays in Voice.

regular portrait/~88 compact landscape, bounded 21-bar wave per side centered
without stretching art. Globe:Space:Delete:Return ≈1:4.35:1.15:1.25 for short
Return. Return default 56, expands single-line; Space yields to 44 minimum, then
bounded Return font scaling. Every action ≥44×44. Compact landscape may two-
column reflow; wide iPad uses centered max width. Qualification is iPhone-first.

Rounded top corners distinguish host. Central activity is sole HoldType mark;
no top logo, transcript, alphabet/number deck, Shift/Caps/123, predictions, Refresh.

Ready/compact failure, never replaced by navigation copy. Microphone opens exact
app setup owner for blocker; repaired user returns and retaps. Healthy cold
request opens swipe-back sheet and auto-starts app capture.
