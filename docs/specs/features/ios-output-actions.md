# iOS Output Actions

- Node type: hybrid
- Status: Historical legacy automatic-delivery contract
- Read when: reviewing pre-V1.1 output, insertion, or acknowledgement evidence.
- Do not read when: deciding current Pending, Latest, History, or handoff behavior.
- Maximum size: 100 physical lines.

This source described accepted-text recovery plus optional keyboard insertion.
Its automatic-delivery, acknowledgement, wrong-field matching, and History
coupling are not current V1.1 behavior.
