# HoldType 1.0.6

This release adds reusable Text Fixes for macOS and updates the default
transcription model.

## New

- Press `⌥J` in a compatible text field to open a searchable Fixes palette.
  HoldType transforms the current selection, or the complete field when
  nothing is selected.
- Use the built-in Translate and Fix actions, plus Improve Writing, Make
  Shorter, Summarize, Bullet Points, Change to Casual, and Markdown.
- Open `Edit Fixes…` from the menu bar to add, edit, reorder, enable, disable,
  delete, or restore custom Fixes.
- Settings now includes explicit OpenAI consent for Text Fixes. Unsupported,
  secure, changed, or stale text targets remain untouched.

## Changes

- Fresh, missing, or blank transcription model settings now default to
  `gpt-transcribe`. Existing non-blank saved model choices remain unchanged.
- The menu bar now exposes `Fixes…` and `Edit Fixes…` and shows the HoldType
  identity next to the microphone icon.

## Fixed

- Restored focus to the original app before applying a Fix, so transformed text
  is returned to the captured field reliably.
