# HoldType 1.0.11

This release keeps existing Fixes catalogs working after updating HoldType and
adds more control over microphone input and text processing.

## Fixed

- Older saved Fixes catalogs are migrated to the current format instead of
  being rejected as if they came from a newer HoldType version.
- Catalog migration preserves existing Fixes and avoids overwriting the saved
  catalog when compatibility cannot be established safely.

## New

- Choose the system-default microphone or pin a specific input device.
- Keep HoldType out of the Dock by default, with an option to show it there.
- Review local OpenAI usage estimates by category.
- Configure processing models per Fix, including GPT-5.6 profiles.
- Use the bundled Humanize writing skill and voice-prompt Fix actions.
