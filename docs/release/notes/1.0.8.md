# HoldType 1.0.8

This release polishes the macOS editing experience and makes the latest app
download easier to use.

## Improvements

- Manage Fixes, Settings, and Transcript History now use more consistent
  SwiftUI window layouts and return focus reliably when opened.
- The Manage Fixes editor has clearer sidebar controls, including an always
  available Add Fix control, and reopens in front when requested again.
- Transcript History can clear saved recording files in one action while
  protecting recordings that are still being processed.
- The website now highlights Quick Fixes with refreshed product illustrations.
- Download buttons now point directly to the current `HoldType.dmg`, so the
  latest installer link does not require a version number.

## Fixed

- The quit confirmation now completes the app termination flow reliably.
