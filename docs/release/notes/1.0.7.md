# HoldType 1.0.7

This release refines Text Fixes, strengthens dictation recovery, and restores
more flexible keyboard shortcut settings.

## Improvements

- The Fixes palette now presents recent actions first, shows a translation's
  target language, and uses a more compact menu.
- Custom Fixes can be reordered by dragging their sidebar rows; edits save
  automatically as you make them.
- The Fixes editor has a simpler, more focused layout and keeps its title and
  help content stable while you work.
- Keyboard shortcut settings are editable again.

## Fixed

- When a Fix cannot safely use the active text target, HoldType now explains
  the reason in concise, dismissible feedback instead of failing silently.
- Missing recording files now surface as a controlled recording failure rather
  than leaving dictation in an inconsistent state.
- `gpt-transcribe` dictation hints, custom dictionary terms, and usage
  estimates now use the intended model-specific behavior.
