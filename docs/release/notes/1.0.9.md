# HoldType 1.0.9

This release makes transcript recovery more durable and clearer, while refining
the macOS shell and localized landing page.

## Improvements

- Transcript History now persists accepted transcripts across app relaunches,
  while keeping the existing bounded, local-only retention policy.
- Saved recordings and transcription recovery stay in their original
  chronological position when retried or updated, making History easier to
  follow.
- Recovery states now distinguish an ordinary retry from an uncertain earlier
  request. Re-submitting an uncertain recording asks for confirmation first,
  so duplicate transcription is never a surprise.
- Pending transcription-recovery messages are shown after launch, and recovery
  rows provide clearer actions and audio-readiness feedback.
- The menu bar and native quit-confirmation flow have been polished for more
  consistent presentation and focus behavior.
- The landing page now chooses a supported language from the visitor's browser
  preferences on the root route, while preserving an explicitly selected
  language. The Russian download call-to-action and menu illustration were
  also refined.

## Fixed

- An accepted transcript no longer disappears just because HoldType is quit
  and opened again.
