# HoldType 1.0.12

This release improves recording startup responsiveness and makes cancellation
and quick successive recordings more reliable.

## Improved

- Recording preparation and diagnostic file writes no longer block the main
  interface thread.
- The floating recording indicator updates as soon as recording starts,
  without waiting for sound playback or optional camera preparation.
- Recording sounds reuse prepared audio buffers and stop their playback engine
  when idle.

## Fixed

- Releasing the hold shortcut before capture begins cancels the pending start.
  Releasing it after capture begins finishes that same recording once.
- Cancel and Stop no longer compete over the same recording during cleanup.
- Late completion of a cancelled Voice Prompt cannot reset a new recording.

Microphone permissions and recording recovery remain in place. This release
adds no background microphone recording. Dev Vlogs remains a development-only
feature and is not included in the public menu.
