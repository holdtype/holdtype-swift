# HoldType 1.0.10

This release fixes the confirmed quit flow on macOS.

## Fixed

- Confirming Quit now reliably finishes the app's bounded shutdown preparation
  and closes HoldType, rather than leaving the app unresponsive.
- The native confirmation dialog remains frontmost, while Cancel continues to
  leave the menu bar app and future dictation available.
- Updater-initiated relaunches continue to skip the ordinary quit confirmation.
